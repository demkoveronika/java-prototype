# Менеджер будинків — патерн Prototype

## Опис проєкту

Консольна програма на Java для зберігання, перегляду, редагування та копіювання об'єктів будинків із використанням патерну проєктування Prototype (Прототип).

## Функціональність

- Додавання котеджів та багатоквартирних будинків.
- Зберігання площі, кількості поверхів та адреси.
- Зберігання персональних даних власників.
- Перегляд інформації про всі будинки.
- Редагування характеристик будинків і даних власників.
- Створення незалежних копій будинків.
- Перевірка правильності введених даних.

## Патерн Prototype

Prototype (Прототип) — породжувальний патерн проєктування, який дозволяє створювати нові об'єкти шляхом копіювання вже існуючих.

У програмі метод `copy()` створює незалежні копії будинків разом із даними їхніх власників.

Завдяки глибокому копіюванню зміни в копії не впливають на оригінальний об'єкт.

## Структура проєкту

- `Main.java` — головне меню програми.
- `Building.java` — абстрактний клас будинку.
- `Cottage.java` — клас котеджу.
- `ApartmentBuilding.java` — клас багатоквартирного будинку.
- `Owner.java` — клас власника.

## Запуск програми

Компіляція Java-файлів:

```bash
javac -encoding UTF-8 *.java
```

Запуск програми:

```bash
java Main
```

Для правильного відображення українських символів у терміналі Windows може знадобитися налаштування кодування UTF-8.
