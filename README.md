# Лабораторна робота №3

## Тема

Реалізація патерну проєктування Prototype (Прототип) мовою Java.

## Мета роботи

Ознайомитися з патерном Prototype та навчитися
створювати незалежні копії об'єктів.

## Завдання

Розробити програму для зберігання інформації
про котеджі та багатоквартирні будинки.

Кожен будинок характеризується:

- площею;
- кількістю поверхів;
- адресою;
- персональними даними власників.

## Можливості програми

- Додавання котеджів.
- Додавання багатоквартирних будинків.
- Перегляд інформації про будинки.
- Редагування характеристик будинків.
- Копіювання будинків за патерном Prototype.
- Перевірка правильності введених даних.

## Структура проєкту

- `Main.java` — головне меню програми.
- `Building.java` — абстрактний клас будинку.
- `Cottage.java` — клас котеджу.
- `ApartmentBuilding.java` — клас багатоквартирного будинку.
- `Owner.java` — клас власника.

## Використаний патерн

Prototype — породжувальний патерн проєктування,
який дозволяє створювати нові об'єкти шляхом
копіювання вже існуючих.

У програмі метод `copy()` створює незалежні
копії будинків разом із даними їхніх власників.

## Запуск програми

Для компіляції:

```bash
javac -encoding UTF-8 *.java
```

Для запуску:

```bash
java Main
```

Для правильного відображення українських символів
може знадобитися налаштування кодування UTF-8.
